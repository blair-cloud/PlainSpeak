PlainSpeak user guide

Get your local model ready.

Follow this guide once to set up Ollama and Gemma on Windows. After that, PlainSpeak can explain sample notices and your own text without sending it to a hosted AI service.

✓Before you start

PlainSpeak’s current version runs on your Windows computer and uses Ollama for local AI. You’ll need:

  • Python installed on your computer.
  • Ollama for Windows.
  • An internet connection for the one-time model download.

1Install and open Ollama

Download the installer from the official Ollama site. Open Ollama after installation so its local service is running.

Get Ollama for Windows ↗
Already installed? Open Ollama from the Start menu, then continue below.

2Download the model

Open PowerShell and download the default model. This can take a while the first time.

PowerShell
ollama pull gemma3:1b

Want to use a different Ollama model? Replace gemma3:1b in the PlainSpeak model field with the exact model name you downloaded.

Check downloaded models
ollama list

3Start PlainSpeak

Open PowerShell in the offline-form-explainer folder. Run the server:

PowerShell · from the project folder
python server.py

Keep that window open, then visit http://127.0.0.1:8000/. The navbar should show the selected model as ready.

Optional: check Ollama’s local model list
Invoke-RestMethod http://127.0.0.1:11434/api/tags

4Try your first document

  • Choose one of the fictional samples, or paste text from a document.
  • Select Explain this document.
  • Compare every action, date, or amount with its source quote.
  • Use Copy notes or Download .txt to keep the explanation.
Remember: AI can misunderstand a notice. Verify important details with the organization that issued it.

?Troubleshooting

“Model not connected”
Open the Ollama app, return to PlainSpeak, then click Check again in the model setup panel.

PowerShell says “ollama is not recognized”
Install Ollama, then close and reopen PowerShell.

“Model not downloaded”
Run ollama pull gemma3:1b, or pull the exact model name shown in the PlainSpeak model field.

The local server won’t start
Make sure you’re in the project folder. If port 8000 is already in use, close the earlier PlainSpeak server window before starting it again.

◇Privacy and safe use

The document text stays in the page until you click Explain. PlainSpeak then sends it to the app’s local Python server, which calls Ollama on your own computer. PlainSpeak does not save the document. Use sample or non-sensitive text while evaluating, and don’t rely on the explanation as legal, financial, or official advice.
